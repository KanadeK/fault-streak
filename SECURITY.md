# Security

Version 0.1.x receives best-effort fixes. This is a local file analyzer: no telemetry, outbound connections, subprocess execution of input content, or automatic input changes. Limits bound normal inputs, not every operating-system resource. Treat reports as potentially sensitive and inspect them before sharing. Do not post private capture data in issues.

For a vulnerability, use [private vulnerability reporting](https://github.com/KanadeK/fault-streak/security/advisories/new). If unavailable, open a minimal issue asking for a private contact without exploit details or sensitive samples. No response-time SLA is promised.
